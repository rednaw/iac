# China travel eSIM — price / GB / days / reviews

Snapshot for the ~1‑month trip (3 phones). **Currency: EUR** (NL). **Prices move**; recheck checkout before buy. Checked ~2026‑10‑01. Living pick lives in [../plans/vpn-travel-china.md](../plans/vpn-travel-china.md) Decide.

**Our usage shape:** maps / WeChat / Alipay / **Didi** / messaging on cellular; Cursor/laptop = hotel Wi‑Fi + OneXray (not eSIM). No Chinese number from any of these (data-only). Smoke: Western app + Didi with OneXray **off**. Phones may take **different brands / GB tiers** (e.g. one heavy 50 GB, two light 20 GB).

**Data model note:** **Total N GB / 30 d** = one shared pool for the whole validity (not N GB per day). **Daily N GB** = refreshes each 24 h; unused daily slice usually does not roll.

Trip.com amounts are **live EUR** on the site. Nomad / Airalo / Holafly list in USD on their sites — table uses **≈ EUR** at ~1.13 USD/EUR (same ratio as Trip.com’s USD vs EUR on the same SKU). Card FX may differ at pay.

## Deep compare — 50 GB total · Trip.com [57042119](https://www.trip.com/things-to-do/detail/57042119?locale=en-XX&curr=EUR) vs Nomad [China 50 GB](https://www.nomadesim.com/china-eSIM) · 2026‑10‑01

Not the same validity: Trip.com **50 GB / 30 d ≈ €21.81**; Nomad **50 GB / 45 d ≈ €30.71** (live EUR on both sites). Sources: product pages + Nomad Plan Details modal + Nomad help (APN / hotspot / China blog).

| Layer | Trip.com 57042119 · Total 50 GB | Nomad Local China · 50 GB |
|--|--|--|
| **Commercial** | Marketplace product; fulfilment via **BillionConnect** (usage portal) | Direct Nomad; wholesale **provider code Jade** |
| **Price (EUR)** | **≈ €21.81** (5% off €22.96) | **≈ €30.71** (€0.61/GB) |
| **Allowance** | **50 GB high-speed total**, then **384 kbps** for remainder of validity | **50 GB** fixed pool (no daily cap on this SKU; unlimited SKUs elsewhere use 512 kbps after daily allotment) |
| **Validity once active** | **30 days** (24 h billing day) | **45 days** |
| **Must activate by** | Within **60 days** of booking | Within **60 days** of purchase (else auto-starts) |
| **Coverage** | **Mainland China only** (excludes HK & Macau) | Mainland China; page notes overseas territories may be excluded; Greater China sold separately |
| **Radio / MNO** | **China Mobile (CMCC)** | **China Unicom + China Telecom** (manual switch possible) |
| **Air interface** | Marketed **5G**; real speed location/device dependent | **5G/4G** |
| **APN** | Documented: **`cmhk`** (manual if needed) | Auto on most phones; Jade → **`mobile`** if manual ([APN help](https://www.nomadesim.com/help-center/en/articles/9886316-what-are-the-apn-settings-for-my-nomad-esim)) |
| **IP / GFW path** | Explicit: **CN-developed apps → HK IP**; **non-CN apps → SG IP** | States international routing outside mainland (Google/WhatsApp/etc. without separate VPN); **no published HK/SG split table** |
| **Hotspot** | Listed **supported**; FUP text discourages heavy share / streaming as throttle risk | Plan Details: **Hotspot Yes**; help: supported, stability not guaranteed |
| **Voice / SMS / +86** | Data plan; no usable CN number for our purposes | **Data only**; local number **No** |
| **Install** | QR / SM-DP+; Trip app install; **1 QR → 1 device**; reinstall **≤10× same device** | QR; install before travel |
| **Activation** | Data roaming on; their copy says turn **off primary SIM** (awkward if you need KPN SMS — dual-SIM data on eSIM + KPN voice/SMS is the usual tourist pattern; treat their “off” as anti-roaming charge caution) | Keep home SIM; eSIM = cellular data; roaming **on** for Nomad line only |
| **Top-up** | **Renewal** = separate plan on **same device**; not merged allowance | **Add-on Yes**; can buy add-on **in China** if base still active; **cannot buy new China plan** once inside mainland |
| **Usage check** | [BillionConnect usage](https://flow-consumer-center.billionconnect.com/usageq/trip/en) | Nomad app / manage |
| **Cancel** | Free until 00:00 day before expiry (unactivated); **no cancel after activation** | Nomad refund policy (see plan modal) |
| **FUP** | Carrier may throttle “large amounts in short period”; avoid prolonged stream/download/hotspot | Not spelled on 50 GB modal beyond data-only |
| **Support** | Trip.com / fulfilment partner | Nomad in-app / live chat |
| **Multi-city / HSR** | Single MNO (CMCC) | Dual MNO (Unicom/Telecom) — more failover options |

**Technical takeaway:** same tourist class (international-breakout data eSIM), different pipes. Trip.com = **CMCC + `cmhk` + published HK/SG app split + cheaper/shorter**. Nomad = **Unicom/Telecom + Jade/`mobile` + longer validity + add-ons in-country + dual-network failover**. Neither replaces hotel Wi‑Fi + OneXray for the Mac.
